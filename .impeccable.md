# .impeccable — contexto de design do App "AI Savings"

## Design Context

### Users
Clientes e prospects da Databricks usando o app em **self-service** — sem um SA por perto.
Perfil: liderança técnica / FinOps / plataforma de IA de uma empresa avaliando quanto poderia
economizar no consumo de LLMs. Eles chegam com dados do consumo atual (planilha exportada de
billing/observabilidade) e querem, em poucos minutos, uma estimativa crível de economia ao
mudar o mix de modelos (incluindo alternativas OSS mais baratas de performance equivalente).
Contexto de uso: navegador, desktop, horário comercial, avaliando uma decisão de custo — então
a interface precisa ser **autoexplicativa e transmitir credibilidade** (é um número que vão
levar para um comitê). Também é usado ao vivo por SAs em conversas, então deve ficar bonito
projetado numa tela.

### Brand Personality
Identidade visual **Databricks — produto, tema claro**. Três palavras: **confiante, preciso,
engenheirado**. Sério com dinheiro (é uma calculadora financeira), mas não corporativo-sem-alma;
a "recompensa" (economia potencial) pode ter um momento de destaque. Nada de hype de IA.

### Aesthetic Direction
- **Tema**: claro. Fundo oat/off-white (não branco puro), superfícies levemente elevadas.
- **Paleta (OKLCH, tintada para o navy Databricks)**:
  - Tinta/ink primário = **Databricks Navy `#1B3139`** (texto, estrutura).
  - Acento de marca = **Databricks Lava `#FF3621`** (raro, 10%): CTA principal, número-herói
    da economia, destaque do cenário sugerido.
  - Neutros oat/cream tintados para o hue do navy; sem cinza puro sobre cor.
  - Positivo (economia/delta pra baixo no custo) pode usar Lava como "ganho" da marca; um verde
    considerado só para micro-deltas se necessário.
  - Banir paleta "IA": ciano-no-escuro, gradiente roxo→azul, neon.
- **Tipografia** (fugindo dos defaults banidos — nada de DM Sans/Inter/Space Grotesk/IBM Plex):
  - **Display / títulos**: `Bricolage Grotesque` — grotesca com caráter editorial-engenheirado,
    boa para o título dinâmico "US$ XX de economia potencial".
  - **Corpo / UI / tabelas**: `Hanken Grotesk` — limpa, legível, com `tabular-nums` para todos
    os números (tabelas e cards de custo).
  - **Números-herói / slugs de modelo**: opcionalmente `Geist Mono` (uso cirúrgico, alinhamento
    tabular e textura de "precisão"; nunca como vibe geral de "técnico").
- **Anti-referências**: dashboard admin genérico com cards iguais em grid; stripes coloridas na
  borda esquerda; gradient text; modais desnecessários; tudo centralizado.

### Design Principles
1. **O número manda.** A economia potencial é o herói — hierarquia tipográfica e o acento Lava
   servem a ele. Todo resto é suporte.
2. **Planilha-nativo.** As tabelas de entrada e de orçamento têm que parecer/comportar como
   planilha (colar do clipboard, editar célula, tab entre campos) — é o gesto central do usuário.
3. **Mostre a transformação, não só o total.** A visualização final conecta visualmente o mix
   atual ao sugerido (linhas ligando barras por tier); o insight é a *migração* de consumo.
4. **Credibilidade acima de flash.** Disclaimers claros de que é estimativa, origem dos dados
   (AA + régua de faturamento) visível; nada que pareça número inventado.
5. **Progressive disclosure.** Provider + colar tabela → classificação → orçamento → gráfico.
   Cada etapa se revela ao completar a anterior; estado vazio ensina o próximo passo.
